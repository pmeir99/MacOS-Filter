# Body-skin evaluation

First candidate: [Google's SelfieMulticlass model card and weights](https://huggingface.co/litert-community/MediaPipe-ImageSegmenter-Selfie-Multiclass). The published six classes distinguish body skin and facial skin. Hands and neck have no independent label. Use body skin (index 2) as the first test target. A separate set of annotations should mark policy exemptions before evaluating the household rule.

Run the reference evaluator in a local Python environment with mediapipe, numpy and pillow. Supply the published TFLite weights and a local JSON list such as [{"image":"example.jpg","mask":"skin.png","group":"group-photo"}]. Keep evaluation images private. Black means background, white means target body skin. Record the model SHA-256, OS, processor and runtime versions with the report. The script measures segmentation time only. Time the full browser path separately.

Use independent photos covering portraits, distant people, crowds, bare arms, skin-colored clothing, different lighting and skin tones, mannequins and empty product shots. Inspect missed region area per person as well as aggregate precision and recall. Compare whole-frame inference with person crops generated by Vision for small figures. Measure the cost of additional crops and their effect on mask boundaries before shipping. A community-standard policy needs explicit decisions for hands, neck, sleeves and garment type. Maintain separate tests for these.

Priorities after render verification:
1. Ensure the pixels analyzed match the visible source. Refetching a CDN URL can return a different rendition. Test authenticated sources, responsive candidates, animations and rapidly recycled cards.
2. Check crops and rotation under browser zoom and CSS transforms, including portrait images. Measure first visible unfiltered frames during insertion and source swaps.
3. Record latency from discovery to filtered paint, peak memory and queue drops on a physical M4/16 GB under scrolling load. Compare the reference LiteRT pipeline with a native conversion only after matching output pixels on identical inputs.
4. Benchmark apparel/product recognition separately using unlabeled product photos, packages, mannequins and ordinary household objects as negatives. NudeNet localizes exposed anatomy, while an empty product photograph may have no person at all. Use separate product labels and explicit-content scores in the policy.
5. Enable additional controls only for the specific categories and image conditions that have been evaluated. Use the full cover for uncertainty under the strict preset.

This experiment is outside the shipped app. No page images are collected and no user upload is needed.
